# KATA Cypress

Projet réalisé dans le cadre de ma formation QA Tester.

## Objectif

Automatiser les tests fonctionnels d'un formulaire HTML avec Cypress afin de vérifier le bon fonctionnement des interactions utilisateur.

## Scénarios de test

- Ouverture de l'application
- Remplissage du formulaire
- Vérification des champs obligatoires
- Validation des données saisies
- Contrôle du comportement de l'application

## Technologies utilisées

- Cypress
- JavaScript
- HTML

## Compétences développées

- Automatisation des tests
- Tests fonctionnels
- Rédaction de scénarios de tests
- Validation d'une interface utilisateur
- Détection et analyse des anomaliesExemple de formulaire en HTML5 et CSS
